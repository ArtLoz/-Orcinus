# Публикация Orcinus

Как выпустить Orcinus в открытый доступ и в Google Play, не нарушив лицензий.

## 1. Что уже готово в репозитории

| Что | Где |
| --- | --- |
| Лицензия проекта — GNU AGPL v3.0 (лицензия OrcaSlicer) | `LICENSE` |
| Страница «О программе»: авторские права, отказ от гарантий, текст лицензии, ссылка на исходники, благодарности, отказ от связи с OrcaSlicer | `:feature:about`, пункт в боковой панели |
| Тексты лицензий всех компонентов APK (111: библиотеки Android, ядро Orca и его нативные зависимости, шрифт) | `app/notices`, `scripts/notices/update_notices.py`, плагин AboutLibraries |
| Шрифт со свободной лицензией (Inter, OFL 1.1) вместо HarmonyOS Sans | `scripts/subset-fonts.ps1` |
| Своя иконка без логотипа OrcaSlicer | `branding/icon.svg`, `app/src/main/res/drawable/ic_launcher_foreground.xml` |
| Релизная сборка: R8, сжатие ресурсов, подпись вне git, запрет релиза без ссылки на исходники | `app/build.gradle.kts` |
| Выравнивание нативных библиотек под страницы 16 КБ (требование Play) | NDK r28: сегменты `LOAD` по `0x4000`, `zipalign -P 16` проходит |
| Тексты и графика для магазина (en-US, ru-RU), совместимо с fastlane и F-Droid | `fastlane/metadata/android` |
| Политика конфиденциальности | `docs/privacy-policy.md` |

## 2. Что сделать до первой публикации

1. **Публичный репозиторий** — https://github.com/ArtLoz/-Orcinus, адрес указан в
   `gradle.properties` (`orcinus.sourceUrl`). Без него релизная сборка
   останавливается задачей `checkSourceUrl`: AGPL требует дать получателю
   программы доступ к её исходному коду.
2. **История git.** В старых коммитах лежат урезанные шрифты HarmonyOS Sans
   (`core/designsystem/src/main/res/font/orca_sans_*.ttf`), а их лицензия
   запрещает изменения. В публичный репозиторий выкладывать историю без них:
   либо один начальный коммит с текущим состоянием, либо
   `git filter-repo --path-glob 'core/designsystem/src/main/res/font/orca_sans_*' --invert-paths`.
3. **Продукт.** Сейчас в приложении один набор профилей (Creality K2 Plus).
   Для открытого релиза в магазине нужен выбор принтера и материала, иначе
   приложение бесполезно большинству пользователей. Остальные пункты этапа 4 —
   по плану.
4. **Язык.** Интерфейс только на русском. Для публикации на другие страны
   нужны английские строки (`values/` — английский, `values-ru/` — русский).
5. **Политика конфиденциальности по адресу в интернете.** Разместить
   `docs/privacy-policy.md` как страницу, например
   `https://shadow.orcinus.app/privacy`, или ссылкой на файл в публичном
   репозитории.

## 3. Ключ подписи

Google Play подписывает приложение своим ключом (Play App Signing), а мы
подписываем загружаемый бандл ключом загрузки. Ключ загрузки создаётся один раз
и хранится вне репозитория, с резервной копией:

```powershell
& "$env:JAVA_HOME\bin\keytool.exe" -genkeypair -v -keystore C:\keys\orcinus-upload.jks -alias upload -keyalg RSA -keysize 4096 -validity 10000
```

`keystore.properties` в корне репозитория (он в `.gitignore`):

```properties
storeFile=C:/keys/orcinus-upload.jks
storePassword=...
keyAlias=upload
keyPassword=...
```

Для CI те же значения задаются переменными `ORCINUS_KEYSTORE_FILE`,
`ORCINUS_KEYSTORE_PASSWORD`, `ORCINUS_KEY_ALIAS`, `ORCINUS_KEY_PASSWORD`. Без
ключа релизная сборка собирается неподписанной.

## 4. Сборка релиза

1. Увеличить `versionCode` и `versionName` в `app/build.gradle.kts`, добавить
   `fastlane/metadata/android/<язык>/changelogs/<versionCode>.txt`.
2. Если менялись нативные зависимости или шрифт — `python scripts/notices/update_notices.py`.
3. Собрать бандл:

   ```powershell
   .\gradlew.bat :domain:test :data:notices:test :feature:about:testDebugUnitTest :app:bundleRelease
   ```

   Результат: `app/build/outputs/bundle/release/app-release.aab`.
4. Проверить на телефоне релизную сборку (R8 может удалить то, что нужно JNI
   или навигации): запуск, импорт STL, нарезка, отмена, «О программе» →
   «Сторонние компоненты» → текст лицензии.

   ```powershell
   .\gradlew.bat :app:assembleRelease
   adb install -r app\build\outputs\apk\release\app-release.apk
   ```

5. Проверка выравнивания 16 КБ (Android SDK build-tools):

   ```powershell
   & "$env:LOCALAPPDATA\Android\Sdk\build-tools\37.0.0\zipalign.exe" -c -P 16 -v 4 app\build\outputs\apk\release\app-release.apk
   ```

6. Поставить тег на коммит релиза (`git tag v0.1.0`) и опубликовать его вместе
   с submodule OrcaSlicer: исходники каждой выпущенной версии должны оставаться
   доступными.

## 5. Google Play Console

1. **Создание приложения.** Название `Orcinus`, приложение, бесплатное.
   Имя пакета `app.orcinus.shadow` после первой загрузки изменить нельзя.
2. **Новый личный аккаунт разработчика.** Перед выходом в рабочую версию Google
   требует закрытое тестирование: не меньше 12 тестировщиков в течение 14 дней.
3. **Доступ к приложению:** все функции доступны без входа.
4. **Реклама:** нет.
5. **Возрастной рейтинг:** анкета IARC, категория «Утилиты», пользовательского
   контента и общения нет.
6. **Целевая аудитория:** взрослые (18+), приложение не для детей.
7. **Безопасность данных:** данные не собираются и не передаются. Приложение не
   запрашивает `INTERNET`, аналитики и отчётов о сбоях нет.
8. **Разрешение `FOREGROUND_SERVICE_SPECIAL_USE`.** В декларации разрешений
   описать использование и приложить видео:
   - описание: «Нарезка выбранной пользователем 3D-модели в G-code ядром
     OrcaSlicer. Запускается пользователем кнопкой „Нарезать“, длится от секунд
     до минут, показывает уведомление с ходом и кнопкой отмены и завершается
     вместе с задачей. WorkManager не подходит: нарезка начинается сразу по
     действию пользователя и не должна откладываться системой»;
   - видео: импорт модели → «Нарезать» → выход из приложения → уведомление с
     ходом → «Отменить» или завершение.
9. **Политика конфиденциальности:** адрес из раздела 2.
10. **Страница в магазине:** тексты из `fastlane/metadata/android/<язык>/`,
    иконка `icon.png` (512×512, 32 бита), обложка `featureGraphic.png`
    (1024×500) из `fastlane/metadata/android/en-US/images`, минимум 2 снимка
    экрана телефона (и планшетов, если приложение для них заявлено). Графику
    перерисовывает `python scripts/render-branding.py`.
11. **Товарные знаки.** Не использовать логотип и название OrcaSlicer как имя
    приложения или его часть; упоминать OrcaSlicer только как ядро, с отказом
    от связи (он уже есть в описании и на странице «О программе»).

## 6. Обязательства по лицензиям при каждом выпуске

- Исходный код, соответствующий бинарнику, опубликован: тег в публичном
  репозитории и адрес в `orcinus.sourceUrl`.
- Страница «О программе» показывает лицензию и ссылку на исходники; тексты
  лицензий компонентов актуальны (`update_notices.py` после обновления Orca).
- Изменения относительно OrcaSlicer отмечены: Orca подключена submodule без
  правок, всё своё — в этом репозитории с его историей.
- Сторонние лицензии, требующие упоминания в документации (FreeType, IJG,
  OpenCASCADE), перечислены на странице «Сторонние компоненты».

## 7. F-Droid (по желанию)

Структура `fastlane/metadata/android` подходит F-Droid. Приложение не содержит
закрытых компонентов и сетевых библиотек; вся нативная часть собирается из
исходников по закреплённым рецептам Orca, поэтому сборка на сервере F-Droid
возможна, но займёт больше часа из-за зависимостей.
